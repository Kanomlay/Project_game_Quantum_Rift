# ชุดสกิลฮีโร่ Quantum Rift

อ้างอิงชื่อทักษะจากตารางอาชีพใน Project2/เอกสาร/เปิดประตูสู่มิติควอนตัม.docx และตรวจเทียบกับเอกสาร Project1 พบ 4 อาชีพ อาชีพละ 2 สกิล

| อาชีพ | แถวบน 7 เฟรม | แถวล่าง 7 เฟรม |
| --- | --- | --- |
| Warrior นักรบ | พุ่งชนกระแทก | เกราะสะท้อนกลับ |
| Archer นักธนู | ลูกศรทะลวงมิติ | ย่างก้าวเงา |
| Inventor นักประดิษฐ์ | โดรนจู่โจม | กับดักแม่เหล็กไฟฟ้า |
| Mutant มนุษย์กลายพันธุ์ | คมเขี้ยวดูดกลืน | กระตุ้นเซลล์ |

รวม 56 เฟรมเอฟเฟกต์ และ 8 ไอคอน ไม่รวมตัวฮีโร่หรือมือ สามารถแสดงแยกจากแอนิเมชันตัวละครได้

ไอคอนในแผ่นรวมเรียงซ้ายไปขวา แถวบน: พุ่งชนกระแทก เกราะสะท้อนกลับ ลูกศรทะลวงมิติ ย่างก้าวเงา แถวล่าง: โดรนจู่โจม กับดักแม่เหล็กไฟฟ้า คมเขี้ยวดูดกลืน กระตุ้นเซลล์

## ขอบเขตและสถานะ

- สร้างด้วยเครื่องมือสร้างภาพในตัว ตามคำอธิบายใน PROMPTS.md
- เอกสารระบุชื่อสกิล แต่ไม่ได้ลงรายละเอียดจังหวะภาพครบทุกทักษะ จังหวะชาร์จ ปล่อย และสลายเป็นการออกแบบภาพเพิ่มเติม ไม่ใช่การกำหนดดาเมจ ระยะ หรือคูลดาวน์
- final เป็นชุดที่ลบลายตารางและเก็บขอบด้วยสคริปต์ตามที่ผู้ใช้ยืนยันแล้ว ภาพ PNG มีช่อง alpha โปร่งใสจริง ส่วน source เก็บภาพต้นฉบับที่ยังมีตารางไว้แยกต่างหาก
- ยังไม่ได้แก้ Scene, Prefab, Animator หรือระบบสกิลใน Unity
- ตรวจโปรเจกต์จริงพบชื่อนักรบทั้งสองสกิล แต่มี Dash ผูกใช้งานอยู่เพียงช่อง Q ส่วนช่อง E ยังไม่ผูกสกิล

## ไฟล์สำหรับใช้งาน

- final/ชื่ออาชีพ/ชื่อสกิล/ มี PNG รายเฟรม _01 ถึง _07 เฟรมละ 256 × 256 พิกเซล
- final/ชื่ออาชีพ/ชื่อสกิล-7Frames.png เป็นแผ่นแนวนอน 1792 × 256 พิกเซล ตัดเป็น 7 ช่องขนาดเท่ากัน
- final/Icons/ มีไอคอนแยก 8 แบบ ขนาด 256 × 256 และชุดย่อ 64 × 64 แบบ nearest-neighbor
- final/All-Skills-Preview.gif ใช้ดูภาพเคลื่อนไหวรวมทั้ง 8 สกิล พื้นสีเข้มในภาพตัวอย่างไม่ใช่พื้นหลังของ PNG
- final/manifest.json ระบุชื่อไทย จำนวนเฟรม และข้อมูลการแยกไฟล์
- final/QA.json เก็บผลตรวจจำนวนภาพ ความโปร่งใส ขอบภาพ และการเรียงเฟรม

## แนวทางใช้ใน Unity ภายหลัง

ตั้ง Texture Type เป็น Sprite, Filter Mode เป็น Point, Compression เป็น None และปิด Mip Maps สำหรับเอฟเฟกต์เลือก Sprite Mode แบบ Multiple แล้ว Slice เป็น Grid by Cell Size 256 × 256 ใช้ Pivot กลางและเรียง _01 ถึง _07

GIF ใช้ 10 เฟรมต่อวินาทีเพื่อให้เห็นจังหวะชัด ไม่ใช่คูลดาวน์หรือเวลาร่ายสกิลที่บังคับใช้จริง ตัวอย่าง Dash ในโปรเจกต์ใช้ระยะเวลา 0.2 วินาที หากต้องการเล่นภาพครบ 7 เฟรมภายในช่วงนั้นต้องกำหนดเวลาคลิปให้สอดคล้องกันตอนเชื่อมระบบ

เอฟเฟกต์พุ่งและลูกศรหันไปทางขวา สามารถหมุนให้ตรงกับทิศเล็งได้ ส่วนกับดักและออร่าเป็นภาพมุมมองสำหรับเกม 2D จากด้านบน จังหวะหลังเฟรม 7 อาจหยุด ลบเอฟเฟกต์ หรือวนซ้ำตามความสามารถจริง โดรนและกับดักมีเฟรมพักสำหรับเริ่มรอบใหม่
