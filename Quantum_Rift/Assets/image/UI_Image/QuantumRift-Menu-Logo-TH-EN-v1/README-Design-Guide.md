## ข้อความเมนู

| หน้าที่ | English | ไทย |
| --- | --- | --- |
| เริ่มเกมใหม่ | START | เริ่มเกม |
| โหลดความคืบหน้าเดิม | CONTINUE | เล่นต่อ |

## แนวทางภาพและการจัดหน้า

สีต่อไปนี้เป็นค่าสีเป้าหมายสำหรับต่อยอด ไม่ใช่การรับประกันว่าทุกพิกเซลในภาพใช้เฉพาะค่าสีนี้

- พื้นเข้ม: #080D20
- ผิวปุ่ม: #211637
- กรอบโลหะม่วง: #665185
- สีเลือก/โฟกัส: #24E4FA
- พลังมิติ/สีเสริม: #9138E8
- ข้อความหลัก: #F3F3FF
- ข้อความไม่พร้อมใช้: #8F8DA4

หน้าเมนู: โลโก้และปุ่มอยู่ด้านซ้าย ภาพประตูมิติเป็นจุดเด่นด้านขวา ไม่วาง HUD เลือดหรือเงินบนหน้าชื่อเกม
การโฟกัสใช้ทั้งขอบฟ้าและสัญลักษณ์เพชร ไม่พึ่งสีเพียงอย่างเดียว
ปุ่มเปล่าสี่ไฟล์แสดง Normal / Focused / Pressed / Disabled; ไอคอนมี Settings, Pause แบบ Focused, Sound, Close แบบ Disabled เท่านั้น ยังไม่ครบทุกสถานะของทุกไอคอน
ใช้การย่อ/ขยายรักษาสัดส่วนและตัวกรอง Point/Nearest เมื่อต้องการรักษาขอบพิกเซล
ภาพปุ่มมีข้อความในตัว เปลี่ยนถ้อยคำไม่ได้โดยการพิมพ์ทับไฟล์ หากต้องการหลายภาษาแบบเปลี่ยนได้ ให้ใช้ปุ่มเปล่าแล้ววางข้อความเป็นอีกองค์ประกอบ

## แนวทางฟอนต์ RIFT PIXEL

สถานะ: แบบร่างลักษณะตัวอักษร ไม่ใช่ TTF/OTF, ไม่ใช่ bitmap font ที่มีข้อมูล metrics, และยังไม่มี glyph ไทยครบชุดหรือระบบจัดวรรณยุกต์

- Display: หัวเรื่องและโลโก้ใช้ทรงเหลี่ยมหนา ขอบดำ และไฮไลต์ฟ้า–ม่วง
- UI: ปุ่มใช้สีขาวเรียบ มีรายละเอียดน้อยกว่าหัวเรื่องเพื่อให้อ่านเร็ว
- ไทยควรคงหัวอักษรและความต่างของตัวใกล้เคียง เช่น ข/ช/ซ และ ค/ด/ต
- เว้นพื้นที่ด้านบนสำหรับสระและวรรณยุกต์ซ้อน รวมถึงด้านล่างสำหรับ ุ/ู ไม่ตัดกรอบข้อความชิดฐานอักษร
- ข้อความเนื้อหา/คำอธิบายไม่ควรใช้ขอบหนาและเอฟเฟกต์แบบโลโก้
- ก่อนทำเป็นฟอนต์จริง ต้องวาดชุดอักษรครบ ตรวจรูปสระผสม/วรรณยุกต์ ระยะอักษร และทดสอบคำไทยในระบบเกมจริง ไม่ควรตัดแผ่นตัวอย่างนี้ไปอ้างว่าเป็นฟอนต์พร้อมใช้
