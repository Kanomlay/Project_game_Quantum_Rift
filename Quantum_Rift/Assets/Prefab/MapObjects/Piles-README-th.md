# กองกล่องประจำห้องและแนวหนามทางเดิน

กองกล่องและหนามในชุดนี้วางตำแหน่งตายตัว ไม่ได้สุ่มใหม่เมื่อเข้าเกม
ระบบเลือกผังแมพและสุ่มของตกแต่งเดิมยังทำงานตามปกติ

- ห้องต่าง ๆ: `Room > FixedGameplayObjects > Pile_*`
- ทางเชื่อม: ใต้ผังแมพแต่ละแบบ `FixedCorridorTraps > SpikeStrip_*`
- กล่องแต่ละชิ้นยังทำลายได้และมีโอกาสดรอปเลือด/พลังงานเดิม
- หนามมีสัญญาณเตือน พุ่งทุก 10 วินาที และหุบให้เดินผ่านได้

กองสำเร็จรูปสำหรับลากเพิ่มอยู่ใน `Spaceship/Piles` และ `Forest/Piles`
มี Circle, Heart, Rectangle, LShape, Steps, TwinStacks และ Compact
ลากทั้งกองไว้ใต้ห้องที่ต้องการแล้วขยับตำแหน่งได้ หรือขยับ/ลบกล่องรายชิ้นได้
เว้นพื้นที่หน้าประตู จุดวาร์ป จุดเกิด และทางเดินรอบกอง

แต่ละแมพมี 3 ผัง ถ้าต้องการแก้ทุกผังให้จัดวางแต่ละผังแยกกัน
ไม่ควรรันเครื่องมือ Arrange Fixed Room Piles And Corridor Spikes ซ้ำหลังจัดตำแหน่งเอง
เพราะเครื่องมือจะสร้างตำแหน่งมาตรฐานใหม่เฉพาะกลุ่ม Pile_* และ FixedCorridorTraps
